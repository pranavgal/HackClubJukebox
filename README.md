# HackClubJukebox
A desk-sized real life replica of the Minecraft Jukebox, comes with all the disks the game offers and a Minecraft chest to store them. Music automatically plays according to the respective disc and stops when taken out. Features an OLED screen with animations and text showing the currently playing disk, how long it has been playing for, the amount of time left in the song, and an animation of the current disc spinning. Will feature a power switch near the bottom with a battery compartment at the side or the bottom. Painted like pixel art and will be fully 3d printed with PLA. Comes with custom rendezvous song disc by Don Toliver.
